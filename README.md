# Certificador_projetoDisciplinar
API para gerenciamento de eventos acadêmicos, permitindo controlar usuários, eventos, inscrições e certificados. O sistema busca substituir controles manuais por uma solução centralizada, organizada e eficiente, com diferentes perfis de usuários e regras para controlar vagas e evitar inscrições duplicadas.

A API para gerenciamento de eventos acadêmicos, com integração direta ao banco de dados MySQL por meio do SQLAlchemy assíncrono. Foram estruturados os Models e Schemas das principais entidades do sistema, com definição de chaves primárias e estrangeiras e seus relacionamentos. Também foi iniciada a implementação dos endpoints da API, permitindo a comunicação direta entre a aplicação e o banco de dados para operações de cadastro, consulta, atualização e exclusão de dados.
